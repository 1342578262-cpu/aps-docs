# SRPA 文献调研教程

## 检索关键词

```text
second random phase approximation
SRPA | SSRPA | subtracted second RPA | 2p-2h
AND nuclear | Gamow-Teller | M1 | charge-exchange | beta decay
```

## 已发表核验

用 Crossref 确认 DOI、期刊、卷期页码；arXiv 预印本只作为线索，在结果中标注 `preprint`。

## 全文获取优先级

| 来源 | 方式 | 说明 |
| --- | --- | --- |
| APS（PRC / PRL） | harvest 接口 + curl | 官方发布 PDF，已验证可用 |
| Elsevier（PLB 等） | Unpaywall / 学校订阅 | 开放副本或登录后下载 PDF |
| 其他 | Crossref 链接 / OA | 保留摘要 + DOI 并标注可获取性 |

## 输出格式

```text
## 条目
- 标题
- 作者
- 期刊 / 卷 / 页
- DOI
- 年份
- 核心结论
- 全文可获取性: 官方PDF / 开放版 / 仅摘要
```
