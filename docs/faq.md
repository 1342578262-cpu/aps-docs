# FAQ

## 需要安装什么插件吗？

不需要额外插件。依赖你已有的 TeX Live 2024、Codex 捆绑 Python、Qwen 视觉脚本与 APS harvest 接口。

## WoS / ScienceDirect 能直接用吗？

WoS 需要订阅登录，建议用侧边栏浏览器或 Edge 登录后下载 PDF 给我。ScienceDirect 同理，或用 Unpaywall 找开放版。

## 为什么必须区分已发表和预印本？

引用时期刊版有最终卷期页码和 DOI，预印本可能未同行评审或与发表版有差异。清单中会明确标注。

## Qwen 视觉接口的 key 在哪里？

脚本自动读取 `C:\Users\13425\.dashscope_key`，无需手动填写。
