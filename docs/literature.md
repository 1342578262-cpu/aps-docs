# 文献与 BibTeX

调研清单直接生成 BibTeX 条目，引用 key 使用"作者首字母 + 年份"的稳定格式，例如：

```bibtex
@article{Yang2024,
  author  = {Yang, M. J. and Bai, C. L. and Sagawa, H. and Zhang, H. Q.},
  title   = {Magnetic dipole excitations in magic nuclei with
             subtracted second random-phase approximation},
  journal = {Phys. Rev. C},
  volume  = {109},
  pages   = {054319},
  year    = {2024},
  doi     = {10.1103/PhysRevC.109.054319}
}
```
